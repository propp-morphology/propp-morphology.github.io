# Propp's Morphology of the Folktale on one page

https://propp-morphology.github.io/ (English) · https://propp-morphology.github.io/ru/ (Russian)

One page on Vladimir Propp's «Морфология сказки» (Leningrad, 1928): the 31 functions in their order, his symbols (1928,
with the letters of the 1968 English edition), the spheres of action of the seven dramatis personae, and how moves
combine, with his own words and page for each. The worked example is Propp's analysis of «Гуси-лебеди» (Afanasyev
No. 113); counts of how often each function occurs come from his tables of 1928 and 1969.

The page is generated by `scripts/propp/schema_page/build_site.py` in the project's working files (data:
Propp 1928 in the FEB transcription, his tables read from the 1928 print and the 1969 Наука print, the 1968 English
edition for the English terms). Each language is pre-rendered, so the text is in the HTML; the script keeps the page
interactive.
